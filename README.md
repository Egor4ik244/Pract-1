# Unix Shell Emulator (var №13)

Эмулятор командной строки unix-подобной ОС с поддержкой виртуальной файловой системы (VFS) в памяти.

## 1. Общее описание
Программа представляет собой консольный интерфейс (CLI), поддерживающий режим диалога с пользователем (REPL), разбор команд и аргументов по пробелам, а также подключение структуры виртуальной файловой системы (VFS) из внешнего XML-файла.

## 2. Описание функций и настроек
Параметры командной строки при запуске приложения (Этап 2):
- `--vfs <путь>`: Путь к физическому расположению конфигурационного XML-файла файловой системы.
- `--script <путь>`: Путь к стартовому скрипту для автоматического выполнения команд.

Поддерживаемые команды (Этап 1-3):
- `ls`: Команда-заглушка. Выводит свое имя и переданные аргументы.
- `cd`: Команда-заглушка. Выводит свое имя и переданные аргументы.
- `exit`: Завершает работу эмулятора оболочки.

## 3. Сборка и запуск тестов
Скрипт для сборки проекта и ручного интерактивного запуска эмулятора:
```bash
chmod +x run.sh
./run.sh --vfs vfs_deep.xml
```

Скрипт для автоматической компиляции и прогона тестов для трех конфигураций VFS:
```bash
chmod +x test.os.sh
./test.os.sh
```

## 4. Примеры использования
Пример автоматического выполнения команд при запуске с флагом `--vfs`:
```text
=== Debug Configuration ===
VFS Path: vfs_deep.xml
Script Path: startup_script.txt
VFS Name: deep_vfs
===========================
deep_vfs> ls -la /home
Stub ls: arguments = [-la, /home]
deep_vfs> cd level1
Stub cd: arguments = [level1]
deep_vfs> exit
```
