# Unix Shell Emulator (var 13)

Эмулятор командной строки unix-подобной ОС.

## 1. Общее описание
Программа представляет собой консольный эмулятор (CLI) с поддержкой режима диалога с пользователем (REPL), разбором команд и аргументов по пробелам, обработкой неизвестных команд и вызовом команд-заглушек.

## 2. Описание функций и настроек
- `ls`: Команда-заглушка (выводит имя и аргументы).
- `cd`: Команда-заглушка (выводит имя и аргументы).
- `exit`: Завершение работы эмулятора.

## 3. Сборка и запуск тестов
Для сборки проекта и запуска интерактивного режима:
```bash
chmod +x run.sh
./run.sh
```

Для запуска автоматических тестов:
```bash
chmod +x test.os.sh
./test.os.sh
```

## 4. Примеры использования
```text
default_vfs> ls -la /home
Stub ls: arguments = [-la, /home]
default_vfs> exit
```
